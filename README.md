# Jut.su Extension 
Browser extension for [Jut.su](https://jut.su/) (supports dynamic domains like jutsu91.ru)

## Features:
* Automatically plays video 💪
* Automatically skip introduction 🔥🔥🔥
* Open next episode 😎
* Control video playback rate 🎧
* Auto Fullscreen 😎😎
* Fullscreen on "F" press 💻
